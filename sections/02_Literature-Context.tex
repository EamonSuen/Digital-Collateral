  \begin{block}{抵押品的作用}
    \begin{itemize}
      % TODO 什么是信贷配给问题
      \item Stiglitz and Weiss (1981) 提出了\textbf{信贷配给问题}
      \item Bester (1985) 的研究表明，这一问题可以通过将抵押品作筛选工具来(部分)解决:信用风险较低的借款人提供更多抵押品并获得较低利率，从而消除了配给的必要性
      \item 使用抵押品的另一种解释是为了缓解道德风险问题：提供抵押品增加了借款人进行风险转移、逃避责任或策略性违约的成本(Bester 1987;Chan and Thakor 1987;Tirole 2006)
    \end{itemize}
  \end{block}

  \begin{block}{发展中国家的教育}

    \begin{itemize}
      \item 在大多数非洲国家,家庭难以承担教育的自付费用,包括学费、书本费、校服费、餐费和交通费(Williams, Abbott, and Mupenzi 2015)。
      \item Duflo、Dupas 和 Kremer(2021)的研究表明,为已通过入学考试但面临经济困难的学生提供奖学金,不仅提高了他们的中等和高等教育完成率,还改善了其长期劳动力市场表现。
      \item 贷款在高等教育中更为常见,并已在智利、南非和中国等中等收入国家得到研究  (Solis 2017;Gurgand, Lorenceau 和 Mélonio 2023)。 尽管贷款在提高大学入学率方面效果显著,多项研究却发现背负债务毕业的学生会受到负面影响(Cai, Chapman, and Wang 2019; Dearden 2019)。
    \end{itemize}
    
  \end{block}
